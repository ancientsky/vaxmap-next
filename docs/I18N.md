# 多語系（i18n）說明——給翻譯者與維護者

介面字串放在 `public/i18n/<lang>.json`，每個檔案是**扁平的 key → 字串**。`zh-Hant.json` 是原文（source），
其他語系必須有**完全相同的 key**（`npm test` 內的 `tests/i18n.test.mjs` 會檢查）。目前共 232 個 key（不含 `_status`）。

| 語系 | 檔案 | `_status` | 說明 |
|---|---|---|---|
| 繁體中文 | `zh-Hant.json` | `source` | 原文，預設語系（不寫入網址） |
| English | `en.json` | `reviewed` | 已完成 |
| 日本語、한국어、Bahasa Indonesia、Tiếng Việt、ไทย、Filipino | `ja` `ko` `id` `vi` `th` `tl` | `placeholder` | 內容暫為英文，待翻譯。完成後把 `_status` 改為 `draft`（待審）或 `reviewed` |

## 給翻譯者的規則

1. **只改值，不改 key**；不要新增或刪除 key。`meta.*` 已填好（語言名稱、短碼、地區設定），通常不用改。
2. **`{n}`、`{city}`、`{label}` 等大括號參數必須原樣保留**（可調整位置），不可翻譯、不可新增。
   數字會依語系自動加千分位。`{tel}`（1922 連結）、`{n}`（結果數）等會被替換成連結或粗體數字。
3. **單複數**：帶 `.one` 的 key（例如 `results.count.one`）只在數量剛好是 1 時使用，其他情況用不帶 `.one` 的 key。
   語言沒有單複數變化（日、韓、印尼、越、泰、菲律賓語）時兩者填相同內容即可。
4. **不要放 HTML**（`<`、`>` 會被測試擋下）；所有字串都以純文字顯示。可用 `­`（軟連字號）提示長字的斷字位置，
   例如英文 `Pneumo­coccal`。
5. **`glyph.closed`**（地圖圖釘「今日休診」的符號）只能是 `休` 或 `×`（圖釘 HTML 受 Trusted Types 允許清單限制）。
   日文可用 `休`；其他語言建議 `×`。
6. **長度**：`group.*.chip`（主列 4 個按鈕，手機上每個約 85px 寬，最多兩行）、`meta.short`（≤ 4 字元）、
   `period.*.short`（卡片上的時段標籤）、`filters.toggle`、`status.*.text`（徽章）請盡量精簡。
   翻完請在手機寬度（390px）檢查：`npm run test:e2e` 會量測這些元素是否溢出。
7. **不翻譯的內容**：院所名稱、地址、行政區名稱、電話、醫事機構代碼是資料本身，不在語系檔內。
   資料檔另附英文轉寫（`nameEn`、`addrEn`、`cityEn`、`distEn`，見 `docs/DATA_SCHEMA.md`），由 `meta.script` 決定怎麼顯示：
   - `latin`（en、ko、id、vi、th、tl）：卡片／詳細資料以英文名稱、英文地址為主，中文原文放在下一行（較小、灰色，
     `lang="zh-Hant-TW"`，方便出示給計程車司機或櫃檯）；所在地顯示為 `Taipei City · Beitou District`
     （資料的 `cityEn · distEn`，與英文地址一致）；行政區選單與篩選標籤也用英文行政區名。
   - `han`（zh-Hant、ja）：中文為主（日文讀者可讀漢字）；ja 另在名稱下方附英文轉寫（`lang="en"`），
     所在地為「日文縣市名＋中文行政區」（台北市北投區），地址只顯示中文。
   新增語系時依讀者是否能讀繁體漢字決定 `meta.script`。縣市名稱（`city.*`）仍要翻譯（縣市選單、篩選標籤用），
   `city.*` 的翻譯也會成為搜尋別名（例如輸入 “Taipei” 會找到臺北市），所以請用當地通行的拼寫。
8. **品項名稱**（`vaccine.*`、`group.*`）：繁中版直接使用資料檔 `hospitals.json` 的名稱；
   其他語系用這裡的翻譯。產品名、劑型與年齡範圍需與原文一致（例如 Moderna LP.8.1、滿 12 歲以上）。

## 技術說明（維護者）

- `public/js/i18n.js`：`initI18n()` 依序由網址 `#lang=`、localStorage `vaxmap.lang`、`navigator.languages`
  （zh-* → zh-Hant，fil/tl → tl）決定語系，預設 zh-Hant。缺少的 key 退回繁中（開發環境主控台會提示一次）。
  匯出 `t(key, params)`、`tn(key, n)`（單複數）、`tParts()`（參數可為 DOM 節點）、`getLang()`、`setLang()`、
  `tVaccine(id, 'name'|'short')`、`tGroup()`、`tCity()`、`tDist()`、`placeLabel()`、`formatDistanceL()`、`formatTaipeiL()`。
- 院所資料的顯示文字（依 `meta.script`；舊版資料沒有英文欄位時一律退回中文）：
  - `displayName(h) → string`：院所名稱的主要顯示文字（清單、詳細資料標題、地圖圖釘的 `aria-label`／`title` 都應使用）
  - `displayAddr(h) → string`：地址的主要顯示文字
  - `displayArea(h) → string`：所在地（`臺北市北投區`／`台北市北投區`／`Taipei City · Beitou District`）
  - `displayParts(h, 'name'|'addr') → { text, lang, alt, altLang }`：主要文字、第二行（沒有則 `''`），以及與頁面語言不同時
    應設在元素上的 `lang` 屬性（`null` = 沿用頁面語言）
  - `getScript() → 'han'|'latin'`、`learnPlaceNames(hospitals)`（載入資料後呼叫一次，供 `tDist()`／`placeLabel()` 取得英文行政區名）
- 搜尋（`logic.js`，不依賴語系）：不論介面語言，中文欄位與英文轉寫欄位都比對；英文比對不分大小寫、忽略變音符號與隔音號
  （`renai` = `Ren'ai`），拼音可分開輸入（`Lin Wen Zheng` 命中 `Linwenzheng`），一般詞（`ENT`、`Clinic`、`Rd`…）只比對整個字的開頭。
- `setLang()` 不重新載入頁面：更新 `<html lang>`、`document.title`、所有 `[data-i18n]`（文字）與
  `[data-i18n-attr="aria-label:key;placeholder:key"]`（屬性）節點，再通知 `app.js` 重繪清單、詳細資料、標籤、地圖提示。
- `index.html` 內保留繁中原文，作為無 JavaScript 時與載入前的內容。
- `logic.js` 仍為純函式：語系清單與比對（`SUPPORTED_LANGS`、`matchLang`）、網址 `lang`、外文地名別名
  （`tokenizeQuery(q, {aliases})`，別名由呼叫端注入）。
- 新增語系：在 `SUPPORTED_LANGS`（logic.js）加代碼 → 複製 `en.json` 為新檔、改 `meta.*`、`_status: "placeholder"`
  → 在 `index.html` 的 `#lang-select` 加 `<option>`（文字須等於 `meta.langName`）→ `npm test`。
- 未外部化的字串：地圖右下角底圖版權（`© OpenStreetMap 貢獻者`、`© 內政部國土測繪中心`），因為屬於
  Trusted Types 允許清單中的固定 HTML；資料來源錯誤訊息的原文（`data-source.js`，只用於主控台，畫面上依 `error.*` 顯示）。
